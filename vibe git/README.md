# Dev Instruments — тренажёр по Windows CMD и Git

Интерактивный учебный сайт на русском языке: короткая теория, задания с проверкой и две песочницы.
Никакой сборки и внешних зависимостей — чистые HTML, CSS и JavaScript.

## Что внутри

- **Windows CMD** — 48 команд в 6 группах, 35 заданий, виртуальная файловая система с 5 миссиями.
- **Git** — 42 команды, 35 заданий, 8 анимированных сценариев (merge, rebase, cherry-pick, reset, revert, detached HEAD) и командная песочница с 4 миссиями.
- В Git-песочнице есть файловый менеджер (создание, редактирование, удаление и добавление в индекс), просмотр файлов и diff любого коммита по клику на узел графа и разрешение конфликтов слияния.
- **Шпаргалка** — компактные таблицы команд с фильтром и печатью.
- Прогресс (решённые задания, изученные команды, миссии и XP) сохраняется в `localStorage`.

## Запуск

Самый простой способ — открыть `index.html` в браузере.

Для корректной работы буфера обмена и привычных URL лучше поднять локальный сервер из папки проекта:

```powershell
python -m http.server 8000
```

Затем откройте <http://localhost:8000/>.

Подойдёт и любой другой статический сервер, например `npx serve` или расширение Live Server в VS Code.

## Управление

- Теория: карточки раскрываются по клику, изученные команды отмечаются кнопкой.
- Задания: ввод команды, одиночный/множественный выбор, сопоставление и сборка порядка шагов. Есть подсказки и разбор решения. Просмотр решения не засчитывает задание.
- CMD-песочница: настоящие команды (`dir`, `cd`, `copy`, `xcopy`, `findstr`, `sort`, `tasklist`, `set` и другие) над учебной файловой системой.
- Git-песочница: `status`, `add`, `commit`, `branch`, `switch`, `merge`, `rebase`, `cherry-pick`, `reset`, `revert`, `stash`, `tag`, `remote`, `push` и другие. Граф обновляется в реальном времени.
- Прогресс можно сбросить кнопкой «Сбросить прогресс» на странице заданий.

## Ограничения песочниц

Это учебные модели, а не эмуляторы целиком:

- Git-песочница моделирует конфликты слияния маркерами, но сети, хуки и часть флагов упрощены; `push`, `pull` и `fetch` имитируются.
- CMD-песочница не запускает реальные процессы и не меняет файлы на диске.
- XP начисляется за решённые задания и выполненные миссии; 150 XP — новый уровень.

```
assets/js/practice.js      — движок заданий
assets/js/play.js          — песочницы и миссии
assets/js/terminal-cmd.js  — интерпретатор CMD
assets/js/terminal-git.js  — модель Git и команды песочницы
assets/js/graph.js         — отрисовка графа коммитов
assets/js/scenarios.js     — анимированные Git-сценарии
```

Прогресс хранится под ключом `dev-instruments-v2`.
